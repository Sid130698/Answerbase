# Repository workflow

- Use `feature/` for feature branches, as requested by the repository owner. Do not use `codex/`.
- Develop and push features on their own branches; do not push feature work directly to `main`.
- Merge through a pull request only after code review and required checks pass.
- Delete the feature branch only after its PR has been successfully merged.
- Follow the additional frontend instructions in each application's AGENTS.md.
